# Glim

Небольшая панель для ChatGPT, Claude и DeepSeek на macOS.

Этот репозиторий содержит выпуски приложения и подписанный канал обновлений Sparkle. Данные сайтов, аккаунты и переписки сюда не загружаются.

Канал обновлений: https://raw.githubusercontent.com/illiatsygankov-wq/glim/main/appcast.xml

Минимальная система: macOS 13. Нативный Liquid Glass доступен на macOS 26 и новее.
