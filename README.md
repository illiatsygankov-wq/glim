# Glim

Компактная плавающая панель для ChatGPT, Claude и DeepSeek на macOS.

## Скачать

[Скачать Glim 1.4 для Mac с Apple Silicon](https://raw.githubusercontent.com/illiatsygankov-wq/glim/main/updates/Glim-1.4-arm64.zip)

Распакуйте архив, завершите старый Glim и перенесите Glim.app в «Программы». Версии до 1.4 заменяются вручную один раз: в них ещё нет обновлятора.

Начиная с 1.4, приложение проверяет подписанный канал обновлений при запуске и каждые четыре часа. Надпись Update available слева сверху открывает загрузку, установку и перезапуск через Sparkle. Ручная проверка также есть в меню и настройках.

Рекомендуем хранить приложение в /Applications или ~/Applications. Синхронизируемые папки Documents/Desktop могут мешать установщику заменить приложение.

Минимальная система — macOS 13. Нативный Liquid Glass доступен на macOS 26+. Для старых систем используется системный полупрозрачный материал. Сейчас сборка только arm64.

Приложение пока не нотарифицировано Apple и использует локальную подпись; при первой установке macOS может запросить разрешение. Подлинность обновлений отдельно проверяется подписью Ed25519.

Канал: https://raw.githubusercontent.com/illiatsygankov-wq/glim/main/appcast.xml

Этот репозиторий содержит выпуск и канал обновлений. Аккаунты, данные входа и переписки сюда не загружаются.
